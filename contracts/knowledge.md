# contracts/knowledge

## 何时加载

入口 SKILL.md 判模命中“要查具体信息／事实”时加载。

典型信号：

- 用户问“X 是什么”“Y 怎么用”。
- 用户查询产品、配置、版本或官方文档。
- 用户的问题可能命中已发布公共知识卡。

超出 AI／Agent／OpenClaw 社区范围的问题，不使用本 Skill 的知识包。

## 第一步：只通过发布门查询

先读取 `contracts/public-card.md`，再调用：

```bash
node ~/.agents/skills/ai-native-helpdesk/scripts/query-public-card.mjs \
  --query "<用户问题>"
```

调用者明确提供社区知识包时，才增加 `--community-pack "<路径>"`。禁止直接读取 `knowledge/public/` 或社区包中的卡片正文。

### `ALLOW`

- 只使用脚本返回的白名单字段。
- 回答问题，并给一个最小下一步。
- 涉及版本、价格、政策、官方号码等动态事实时，仍需访问当前官方来源复核并标注日期。

### `MISS`

没有已发布卡片命中。转入普通信息检索：优先官方来源，缺证据写 `UNKNOWN`，不假装知识库命中。

### `DENY`

知识包、卡片、状态、路径或查询发生冲突。明确告知“知识卡分支暂不可用”，终止该分支；不直接读卡、不模拟卡片内容、不把拒绝原因扩写成答案。

## 普通信息检索

- 静态信息：回答概念和稳定用法，区分事实与推断。
- 动态事实：访问当前官方来源，标注核验日期。
- 查不到：写 `UNKNOWN`，给一个最小核验动作。

## 输出所有权

- 完整答案或明确的不可用／未知状态。
- 一个最小下一步。

不分析心理动机，不用未经发布的群聊候选，不把机器检查通过写成用户问题已解决。

## 失败规则

- 发布门文件缺失或运行失败：按 `DENY`，不模拟。
- `MISS`：走普通检索，不声称知识库命中。
- 用户问“为什么”：需要因果分析时转 thinking。
- 用户说“做不动”：转 action。
- 用户触红线：转 safety。
