# Issue 2：心理层辅助标注 MVP

- 状态：`CANDIDATE / READY_FOR_REVIEW`
- 范围：主路由完成后的非诊断辅助信号
- 发布边界：本候选不改变 PublicCard、主路由、用户权限或安全决策；继续保持未发布候选，不进入 `main`、安装白名单或 GitHub Release。是否纳入未来 release manifest 另行决策，不属于本 PR。

## 目标

把执行阻力相关的模糊信号收敛为可解释、可复验、可撤回的轻量标签：

- `USER_ADMITS`：用户无保留地直接承认当前执行阻力；
- `BEHAVIORAL_CONTRADICTION`：同一目标、同一时间范围内，明确行为满足至少一条矛盾标准；
- `SUSPECTED`：有保留式自述或其他线索，但证据不足；
- `NONE`：没有足够的执行阻力证据。

这些标签不是诊断结论。没有线索时不猜测；保留式自述不能升级为确定性标签。

## 行为矛盾标准

只有同一目标和时间范围清楚、且没有已知合理约束时，才可使用 `BEHAVIORAL_CONTRADICTION`。实现要求 `main_route_completed=true`、当前回合证据来源为 `USER_CURRENT_TURN`，并通过封闭的 `criterion` 和结构化事实校验：

| 标准 | 最小证据 |
|---|---|
| 时间矛盾 | 声称没时间，但同一期间每天娱乐／刷手机超过 1 小时； |
| 消费矛盾 | 声称要完成同一学习目标，但购买超过 3 个课程／资料且完成率为 0%； |
| 行动矛盾 | 声称想改变同一问题，但超过 7 天没有相关行动； |
| 方向矛盾 | 声称寻找稳定方向，但同一期间更换超过 3 个方向且每个大于 0 天、少于 2 周； |
| 学习矛盾 | 声称正在学习某主题，但明确时间范围内没有提问、实践或输出。 |

单独看到一个数字、一次失败、情绪语气或第三方转述，都不足以触发该标签；任意 `criterion_met` 布尔值不再被接受。

## 输出与安全边界

每次标注必须带 `HIGH`／`MEDIUM`／`LOW` 置信度，并说明可回读证据。主路由完成前不加载本层；安全红线优先转 `safety`。

```text
## 心理层标注
{LABEL} (置信度: {CONFIDENCE})
- 证据：{当前回合可回读证据；没有证据时写“当前没有足够证据”}
- 建议：{仅在非 NONE 时给出最小下一步或转介}
```

默认只做当回合输出。只有用户明确、单独、目的限定、带有效期且可撤回的同意收据，才可分别授权 `FEEDBACK_PERSISTENCE` 或 `SEVEN_DAY_FOLLOW_UP`；7 天跟踪允许 ± 5 分钟时钟容忍范围。拒绝、未回答、过期或撤回时不落盘、不跟踪，并要求受控系统停止已有跟踪。候选脚本只返回 `DECISION_ONLY`，不产生文件或调度副作用。
